# Space Invaders
A classic arcade-style Space Invaders game recreated for learning and fun! Control your ship, blast incoming aliens, and defend earth from invasion.
Features
	•	Move your spaceship left and right to dodge enemy fire
	•	Shoot at and destroy waves of alien invaders
	•	Increasing difficulty as levels progress
	•	Sound effects and classic arcade visuals
	•	Score tracking 
Getting Started
Prerequisites
	•	Python 3.x and Pygame (for Python build)or
	•	Java (for Java build)Update according to your project’s actual dependencies
Installation
Clone the repository:
    git clone https://github.com/Mr-C-Tejesh/Space-Invaders.git
    cd Space-Invaders
Install dependencies:
    pip install pygame

How to Run
Run the game using:
    python space_invaders.py
            or
    java -jar SpaceInvaders.jar
Replace command above as per your project structure

Controls
	•	Arrow keys: Move left and right
	•	Space bar: Shoot
	•	Esc: Quit

Game Play
	•	Survive as long as you can and shoot down all aliens to advance to the next level
	•	Score points for every alien destroyed
	•	Game is over if an alien reaches the bottom or the player ship is destroyed
